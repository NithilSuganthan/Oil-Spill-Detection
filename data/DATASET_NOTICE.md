# Dataset Notice

This workspace contains a downloaded copy of the **CSIRO Sentinel-1 SAR image dataset of oil- and non-oil features for machine learning**, redistributed through Kaggle under **CC BY-SA 4.0**.

- Original authors: David Blondeau-Patissier, Thomas Schroeder, Foivos Diakogiannis, and Zhibin Li (CSIRO).
- Original DOI: https://doi.org/10.25919/4V55-DN16
- Dataset landing page: https://data.csiro.au/collection/csiro:57430
- Kaggle redistribution: https://www.kaggle.com/datasets/harikrishnacs/sentinel-1-sar-oil-spill-detection-dataset
- Content: 5,630 single-band 400×400 Sentinel-1 SAR image chips; 3,725 no-oil/look-alike and 1,905 oil-feature chips.

The trained `csiro_s1_verifier` is an image-chip classifier. It must be credited and redistributed according to CC BY-SA 4.0 requirements. It does not provide pixel masks, georeferencing, spill age, or vessel attribution by itself.
